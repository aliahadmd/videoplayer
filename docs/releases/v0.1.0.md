# Video Player 0.1.0

Initial public release of a native Mac video player built with Swift, AppKit, SwiftUI and libmpv.

## Download and requirements

Download **VideoPlayer-0.1.0-macOS-arm64.zip**, unzip it and move `Video Player.app` into Applications. Requires **Apple Silicon and macOS 27.2 or later**. Intel and older macOS releases are not supported by this bundle.

**This app is ad hoc signed and unnotarized. macOS may block the downloaded app.** Developer ID signing/notarization and a clean second-Mac validation remain future release work. You can also build from the included source. There is no automatic updater.

## Included

- Broad local playback, including MP4, MKV, WebM and audio-only media; direct media URLs.
- Precise seeking, frame stepping, speed with pitch correction, A–B repeat and screenshots.
- Embedded/external subtitles, ASS styling, primary/secondary tracks and subtitle/audio timing.
- Queue ordering/repeat, saved queues, local resume/history and configurable shortcuts.
- Image/geometry controls, codec inspector, native full screen, floating/compact mode and Mac media controls.

The optimized app passed **69 real playback assertions** and **13 model tests** on the development Mac. Playback included H.264, HEVC 10-bit PQ, VP9, AV1, FLAC, subtitle/audio switching, HTTP range seeking, trusted HTTPS, untrusted certificate rejection, rapid queue changes and recovery from corrupt input. The test ran with Homebrew filesystem access denied and loaded all 50 native libraries from the app bundle. See `docs/validation/playback.json` and the completion audit in the source.

## Current limits

OpenGL output; HDR input is tone mapped to SDR. Native HDR and system Picture in Picture are not included. A compact floating player is available. Protected streaming services, online subtitle accounts, translation, recording and plugin/skin loading are outside this release. Physical Bluetooth/multi-display behavior, VoiceOver conformance and sustained energy/long-play benchmarks remain unverified.
