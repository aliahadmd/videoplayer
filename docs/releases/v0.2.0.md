# Video Player 0.2.0

Adds a persistent folder Library and automatic session recovery.

## Downloads and sources

Download **VideoPlayer-0.2.0-macOS-arm64.zip**, unzip it, and move `Video Player.app` into Applications. Requires Apple Silicon and macOS 27.2 or later. This build is **ad hoc signed and unnotarized**; macOS may block a downloaded copy.

The application source is attached as **VideoPlayer-0.2.0-source.tar.gz**. The native libraries, recipes and source lock are unchanged from v0.1.0. Their complete sources remain available as the shared [third-party source archive](https://github.com/aliahadmd/videoplayer/releases/download/v0.1.0/VideoPlayer-0.1.0-third-party-sources.tar.gz), SHA-256 `fdad2bd2d76001ad94ab7b3a464c908a0fb7b160a329e8f30f35a84ed22bef73`. Download both source archives to obtain the application and its dependencies. The dependency-source JSON asset records the same link/hash; source availability is described in `ThirdParty/README.md`.

## New behavior

- **⌘⇧O opens folders into Library.** Expand nested subfolders and play a video in place. Adding/browsing folders leaves current playback alone.
- Folder roots, expanded branches, queue selection/order/repeat and sidebars save automatically. Restarting restores the last local video **paused**, including its position, speed and timing when history/resume are enabled.
- Playback checkpoints save approximately every five seconds and at pause, seek, deactivation, sleep notification and close/quit. Atomic, synchronized writes retain a backup. An abrupt machine failure can still lose the newest changes.
- Disconnected folders stay visible with Refresh/Locate. Relocating a root keeps its layout and updates queued paths. Removing a Library shortcut never deletes media.
- Lazy background reads, natural ordering, skipped hidden/package/link entries, native tree keyboard navigation, and **⌘⇧L** to toggle Library. Return opens the selected file; focused tree arrows navigate without seeking.
- A folder with over 10,000 media files remains fully visible in Library; its playback queue uses an indicated 10,000-item window around the chosen file.
- Existing preferences migrate without resetting custom settings. History/resume and session saving remain separate controls.

## Verification and limits

Passed **20 model tests**, **33 cross-process persistence checks**, and **69 real playback checks**. Persistence checks include an actual forced process kill without shutdown, early-position paused restoration, nested expansion, missing folders, relinking a moved media root, refresh and non-destructive removal. Native UI was inspected in light/dark appearance and through keyboard/file-picker workflows.

Apple Silicon/macOS 27.2+, OpenGL SDR presentation, HDR-to-SDR tone mapping and unnotarized signing remain unchanged. No physical power-cut, multi-display, Bluetooth or sustained energy benchmark is claimed. Protected streaming, native HDR and system Picture in Picture remain outside this release.
