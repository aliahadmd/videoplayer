# Video Player 0.2.1

Full-screen playback now hides its controls automatically.

## Downloads and sources

Download **VideoPlayer-0.2.1-macOS-arm64.zip**, unzip it, and move `Video Player.app` into Applications. Requires Apple Silicon and macOS 27.2 or later. This build is **ad hoc signed and unnotarized**; macOS may block a downloaded copy.

The matching application source is **VideoPlayer-0.2.1-source.tar.gz**. Native dependencies are unchanged from v0.1.0. Their full sources are in the shared [third-party source archive](https://github.com/LiLabsAI/LiPlayer/releases/download/v0.1.0/VideoPlayer-0.1.0-third-party-sources.tar.gz), SHA-256 `fdad2bd2d76001ad94ab7b3a464c908a0fb7b160a329e8f30f35a84ed22bef73`. Download both source archives for the application and its dependencies. The dependency-source JSON records this same link and hash.

## Changes

- During full-screen video playback, the top/bottom bars and cursor hide after three idle seconds. Mouse movement or keyboard input reveals them immediately; hovering over either bar keeps controls available.
- Controls remain visible while paused, buffering, scrubbing, using menus or text fields, navigating with Tab, or opening Library/Queue/Inspector. VoiceOver keeps controls available, and Reduced Motion skips the fade.
- Bars overlay the full-size video without resizing or recreating its native renderer. Full screen starts with sidebars tucked away and restores the saved windowed layout on exit. Esc exits full screen.
- Existing playback shortcuts work while the controls are hidden. Full-screen presentation is temporary and does not overwrite saved Library/queue layout.
